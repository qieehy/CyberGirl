# W1-G2：身份、接收账本与投递证据

2026-11-02。完成桥接合同与持久化基础的离线实现；未启用真实数据库读取器或 UI 发送器。工作台仍使用现有沙盒入口，没有接通真实微信自动回复。

## 已实现

- `bridges/wechat/contracts.py`：账号/数据库代际、进程创建时间/窗口/二进制指纹及会话绑定。会话权限使用规范 username，不用昵称或模糊匹配。绑定结构只验证一致性，真实身份仍需原生读取器提供证据，不能把构造成功当成验证成功。
- 来源消息键由账号、数据库代际、会话类型/username、分片和 local_id 组成。进程重启改变临时绑定，不改变消息键；同正文不同 ID 保留为独立事件。发送者必须明确提供，结构化 @/引用必须带来源证据，正文中的 `@昵称` 不自动生成触发。
- `BridgeStore` 复用同一个 Ledger 连接和事务。每批最多 100 条，按 `(sort_seq, local_id)` 严格排序，消息/处置和游标一起提交，提交后才向读取器返回可 ACK 结果。首次来源需要明确基线；已有游标不能用新基线跳过或重置。
- 提交前失败整批回滚；提交成功但 ACK 丢失可幂等重放已记录批次。混合过期游标和新记录拒绝，读取器须重新取已提交游标。重复 ID/不同内容暂停该绑定，保持原游标，不自动解除冲突。
- 观察模式将指定会话的新文本记录为 OBSERVED，不能进入模型决策，不生成 outbox。自身消息、过期消息、非文本类型保存最小处置和游标，不保存这些跳过项的正文。显式 draft 模式仍需原有主人许可；不自动开放群草稿。
- 来源记录及 inbox 各有 10,000 条上限，满时不确认新进度；绑定和游标各最多 1,000 条。全局暂停停止接收推进。重启后绑定默认失效，需重新核对再绑定，旧游标保留，旧待处理输入不自动补答。
- `Ledger.claim()` 在任何适配器调用前拒绝非文件传输助手、群、失效绑定和旧代际草稿。`require_send_target()` 另提供输入动作前的账号/规范目标/窗口一致性检查；真正的 UI 发送器尚未实现，届时必须调用此检查并复核原生证据。
- 投递证据与发送尝试分开保存。`local_echo` 仍为 UNCONFIRMED；显式人工核对可追加证据并将 UNCONFIRMED 对账为 CONFIRMED，不调用发送器、不新增尝试，保留原尝试的不确定状态。人工凭据与 `platform_message_id` 分开，没有微信消息 ID 时保持空值。既有合成群引用改用独立消息 ID 字段。

## 迁移与验证

SQLite schema 升为 5，新增 bridge_bindings、bridge_cursors、bridge_records、delivery_evidence，及 inbox.bridge_generation / outbox.platform_message_id。打开旧账本前自动备份，新增迁移在事务内；已有 fake 确认记录的合成消息 ID 被保留。回退应另用备份，不能用旧程序覆盖新版账本。

本轮只在测试目录中验证迁移，没有打开或迁移用户正在使用的工作台账本。

新增 5 个综合场景：

1. 身份/代际隔离、昵称和错误目标拒绝、普通 @ 文本不制造结构证据，账本拒绝联系人发送。
2. 接收与游标原子回滚、同序号分页、重放去重、观察零决策/零 outbox、过滤、暂停、容量满及冲突停止。
3. 真实测试子进程在提交后/ACK 前退出；重开后重新绑定，游标和去重事实仍在，不触发决策。
4. 错误回显证据拒绝、本地回显仍未确认、人工对账不重发、人工凭据不冒充消息 ID、重启保留结果。
5. schema 4 → 5 故障回滚、备份、旧人格与已确认消息事实保留。

新增 5 项加受影响的 social/console/groups 13 项，共 **18 passed**；Ruff 通过。随后补强容量和旧回执迁移检查，只补跑对应两项，**2 passed**。没有重复模型、登录或 UIA 实机验收；本轮真实模型请求、微信发送及收藏等内容修改均为 0。

## 下一项与限制

C / W2-A：确定可审查的最小读取依赖，约束账号选择和密钥/解密缓存处理，从明确基线读取限定会话的新消息。尚未证明本机 4.2.0.9 数据库可读、sender 分片映射、分页查询或稳定账号/会话身份。

按任务启用/恢复的运行期协调、可终止 UI 发送工作进程、草稿保护、输入前复核与真实回显关联仍属后续工作；本轮没有宣称这些已完成。尚未增加 IPC、真实桥接 CLI、工作台绑定/人工对账入口或常驻监听。已验明的独立 UIA 实验脚本保持原样。

当前允许的发送目标只有文件传输助手，其他联系人/群只能做获准范围内的观察或本地草稿，不能发送。完整约束见 [操作范围](WECHAT_OPERATION_SCOPE.md)。
