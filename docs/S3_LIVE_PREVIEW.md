# S3 本地真实模型人格预演

2026-10-27，工作台已接入显式的单轮订阅模型预演。复用已有 H4 provider、独立登录和持久代理配置；模型协议与认证方式没有变更。

## 使用

在项目目录启动：

```powershell
& '.\.venv\Scripts\wechat-agent.exe' console --live-model gpt-6.1-sol
```

模型名沿用 H4 与本次实测结果；预演前仍读取当前账号目录并核对可用性，不会自动替换模型。凭据默认目录 `.state/codex`，可用 `--state-dir` 指定。Hiddify 地址继续从项目本地配置读取，无需每次设置环境变量。

使用终端打印的完整 **HTTP 链接** 打开浏览器，不能直接打开 `index.html` 文件。服务重启后访问凭证更新，旧页面需要使用新链接进入。

打开“人格设定”，先保存人格，再在“真实模型 · 单轮人格预演”填写文本并点击按钮。只有这次点击触发真实请求，页面载入、刷新或保存人格不会发起模型请求。未保存的编辑会阻止预演，避免误用另一份配置。普通 `console` 启动仍默认只启用模拟；`--live-model` 开放预演按钮，但启动本身不访问账号。

单轮预演提交已保存人格和本次文本，不带 S1/S2 模拟聊天历史。结果仅作为预演记录保存，不进入 inbox、outbox 或确认聊天历史，也没有投递操作。工作台首页的合成练习仍使用固定模拟模型。

## 行为与恢复

- 复用真实 AI_agent Runtime、空工具集合及受登录代际保护的 ChatEngine。严格解析 SILENT/REPLY；不完整响应或非法结构不会变成可用回复。
- 每次预演独立打开并关闭认证和模型资源，不长期占用凭据锁。若已有终端聊天占用同一登录，预演提示忙；不会强行结束终端进程或另建登录。
- 请求开始前持久登记 UUID、输入指纹、人格/策略版本与提示词指纹。相同 UUID 和输入只返回原记录，修改输入复用 UUID 则返回冲突；服务重启也不会重放旧调用。
- 同时只允许一个预演。暂停或人格更新后，尚未开始推理的请求停止；已经发出的请求可能消耗额度，返回内容会作废，不展示为当前人格的有效结果。
- 超时、失败、取消不会自动补发；沿用 H3 provider 的一次受控 401 恢复机制，HTTP 次数包含该机制可能产生的额外尝试。进程中断遗留 RUNNING 转为 UNKNOWN，不能把未知次数写成零。
- schema 2 → 3 增加独立 previews 表，迁移前保存 `.v2-<时间戳>.bak`；旧消息和人格版本保持不变。最多保留 500 条预演请求，界面显示最近 10 条；达到容量会拒绝新请求，暂未提供删除/归档功能。
- 预演原文、回复保存在本机账本，属于产品数据；诊断证据仅保存状态、计数和内容哈希，不复制正文或凭据。

## 验证结果

新增 3 个关键场景，与受影响的 3 个 S2 场景一起运行，**6 个全部通过**：

1. 真实 loopback API 认证和默认关闭、显式预演、重复与重启幂等，实际 Runtime 接线，零 outbox/adapter 副作用。
2. 人格变更使生成中结果失效、暂停阻止新调用，并发请求不叠加模型调用。
3. 连接失败、取消和模拟进程遗留 RUNNING 的恢复，关闭资源且不重放。

浏览器实际点击完成一次 `gpt-6.1-sol` 短文本人格预演：人格 v2，结果包含“小禾”和“AI 助手”，实际 Runtime，模型 HTTP 尝试 **1 次**，外部消息投递 **0 次**。既有账本仍为 4 条 inbox、3 条 outbox、3 条 attempts、2 个人格版本。页面在窄侧栏宽度下可完成填写和查看结果。

见 [验收截图](evidence/s3-preview.png)与[结构化证据](evidence/s3-result.json)。这不是 H4a 的重复三阶段验收，也不建立真实令牌刷新的独立证据；H4b 继续自然观察。
