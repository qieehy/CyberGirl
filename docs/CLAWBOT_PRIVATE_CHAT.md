## 启动与连接

```powershell
.venv/Scripts/python.exe -m pip install -e '.[clawbot]'
.venv/Scripts/python.exe -X utf8 -m wechat_agent.cli clawbot --port 8765 --live-model gpt-5.6-luna --auto-reply
```

打开终端输出的完整本机认证链接。在工作台点击“获取 / 刷新登录二维码”，使用希望与 Cybergirl 私聊的手机微信扫码并在手机确认。若手机要求验证码，在登录页提交手机显示的验证码。二维码约五分钟有效；过期后手动刷新。

登录结果中的扫码者规范身份绑定唯一允许的私聊。首次连接默认不调用模型、不发消息；阅读数据说明、勾选后点击“授权并开启自动回复”。开启后直接正常聊天，无需测试码。重启加 `--auto-reply` 只恢复同一身份已有授权，不会替首次扫码者授权，也不会补回复启动前消息。

服务需要电脑保持开机、联网和进程运行；目前没有安装系统自启动服务。

## 已接入

- 扫码登录、状态轮询、接收游标持久化、读连接失败退避恢复、登录过期提示重新扫码。
- 仅处理扫码者的新文字，以及微信接口已经提供的语音转写。新消息触发单次模型生成和单次接口回复。
- 沿用 Cybergirl 人格、模型切换、日夜模式、配置、关键词固定回复／忽略规则和日志；每会话最多16对已回复上下文，每天最多30次生成。
- 暂停、消息去重、发送前配置／人格变化检查；发送结果不确定立即暂停，不自动重发。重启将未完成动作保留为 UNKNOWN，不重放。
- 会话 token、回复 context token 和读取游标使用当前 Windows 用户 DPAPI 保护。数据独立保存于 `.state/clawbot/`，模型凭据继续使用 `.state/codex`；不迁移旧聊天正文。

当前未接入图片、表情包图像、文件和群消息。语音仅使用接口自带转写，没有在此路径下载或本机转写语音。接口 `ret=0` 在日志中记为 `API_ACCEPTED`，表示接口受理，不等于对方已读或手机已确认。
