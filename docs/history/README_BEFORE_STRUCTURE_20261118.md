支持 `/reset`、`/logout`、`/exit`。这是本机合成服务，真实订阅入口需显式选择 live、已有登录及账号模型 slug。

输入过长、临时连接失败、超时或限流等错误只结束当前回合，显示原因后仍可继续输入；此前已确认的上下文保留，不自动重发。认证失效和存储错误会停止会话。`--once` 失败仍返回非零退出码，便于脚本判断。退出进程后聊天历史仍会清空。

认证命令为 `auth login`、`auth status`、`auth logout`。默认凭据目录为当前工作目录的 `.state/codex`；跨目录调用时用 `--state-dir` 固定同一路径。`login` 会发起真实认证并显示浏览器登录步骤；H1–H3 使用合成认证，H4 的实际登录与模型验收进度单列记录。

代理已保存到项目根目录的 `wechat-agent.local.toml`，从项目目录启动时自动读取，无需每次设置环境变量。当前配置为：

```toml
[network]
proxy = "http://127.0.0.1:7897"
```

换代理端口时修改该文件；首次在其他目录部署可复制 `wechat-agent.example.toml` 为本地配置。此文件不纳入版本控制，也不随 wheel 分发。临时覆盖配置时仍可设置：

```powershell
$env:WECHAT_AGENT_PROXY = 'http://127.0.0.1:7897'
```

优先级为 `WECHAT_AGENT_PROXY` 环境变量 → 当前工作目录的本地配置 → 直连。显式空字符串选择直连。登录、刷新、模型目录和推理统一使用该配置；只接受本机 HTTP/HTTPS 代理，不自动读取系统代理或通用代理变量。配置损坏时报告错误，代理失败时不会退回直连。mock 和注入的测试传输忽略代理配置。配置在客户端启动时读取，修改后需重启应用。
