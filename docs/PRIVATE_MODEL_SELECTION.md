# 工作台模型切换

工作台新增“回复模型”卡片：加载当前登录 ChatGPT 账号的真实模型目录，选择后点击“切换模型”。无需重启微信或工作台，后续新消息使用新模型。当前使用的模型始终在页面显示。

选择按当前会话保存；下次启动时使用保存值，`--live-model`作为首次默认值。目录请求只读取模型信息，不消耗回复生成额度。未在当前目录中的模型拒绝，网络/登录失败不会悄悄切换到其他模型。

切换会取消旧模型尚未发送的草稿及生成任务，保留生成计数、历史发送与未确认记录；不会补回复旧消息。若原自动回复已开启，切换后恢复等待新消息；原本关闭则保持关闭。后台发送进行中会等待该操作完成，不中断已开始的提交。

认证接口：`GET /api/wechat/models`；同源 `POST /api/wechat/model`，正文包含 `model` 与 `expected_model`。旧页面或并发修改使用不同预期模型时拒绝，要求刷新。

关键检查：模型目录/切换路由、取消旧生成后不发送、保持自动开关、按会话持久化、不清零日额度、无效/陈旧选择保持原模型；与媒体/持续聊天共11项测试通过。页面JS语法和原本地草稿交互检查通过，模拟检查模型与微信发送均0。
