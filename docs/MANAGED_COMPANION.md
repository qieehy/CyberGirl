# 可管理的陪伴与长期记忆

2026-11-18：已接入当前 Amadues → qieehy 普通好友私聊，入口为左侧 **陪伴与记忆**。继续使用原 Cybergirl 人格、当前模型、媒体模块与原微信发送桥，未重新启用 ClawBot。

## 接入方式

从 menglimi 的两个插件移植可独立运行的领域模块：MemoryCompanion 2.6.6 的人物卡、人物分量／衰减系数、记忆分层，以及 PrivateCompanion 7.2.4 的情绪校验模块；原文件、作者、许可证和来源哈希保存在 `backend/src/wechat_agent/companion_vendor/`。

AstrBot 的 Star 生命周期、事件、Provider 和平台发送均由本项目适配实现；没有安装完整 AstrBot 宿主或宣称全部原插件功能可用。当前检索是本地关键词／中文二元词匹配与重要性排序，没有接入上游向量、图谱、多步重建或全部扩展。角色状态与日程目前由管理页维护，不自动生成模拟生活。

## 当前默认行为

- 长期记忆、记录新文本、回复时召回、角色状态注入、阶段摘要开启。
- 主动联系关闭。只有在本页勾选并保存后才开始评估，且仍要求原自动回复开启。
- 只积累启用后的当前联系人新文本及本机已回显的助手回复。不回填启动前旧记录，不读取其他联系人。现有媒体回复继续工作，本版记忆捕获以文本为主。
- 明确的“记住／记一下／别忘了”请求可以直接保存为带来源的记忆；普通对话进入时间线，每20条时间线（用户和助手分别计条）尝试一次阶段总结。
- 总结、主动生成和普通回复共用原每天最多30次模型额度，失败和中断的后台任务也保守占用一次；不会另外获得30次额度。后台任务不与普通回复并发调用模型，新入站优先打断后台生成。
- 首次载入时是空记忆库。用户正常聊天即可，无需测试码。

## 可以管理什么

1. 分别启停记忆、记录、召回、角色状态、自动摘要和主动联系，或点击“暂停全部陪伴与记忆”。
2. 编辑人物称呼、关系、分量、备注，以及角色心情、精力、活动、位置和日程。
3. 添加、搜索、编辑记忆，指定事实／偏好／事件／约定／摘要、重要性和置顶。
4. 遗忘单条或全部记忆，已遗忘列表可恢复；遗忘从后续长期召回中排除，不删除原聊天账本。编辑或遗忘时原来源退出待总结范围，已有其他独立记忆应分别管理。
5. “预览召回”展示某个话题本轮将使用的资料，零模型、零微信发送。
6. 查看后台任务、共享模型用量，手动生成一次摘要，导出当前管理数据。

摘要保留所引用的原始来源 ID，作为模型整理结果而非已核实事实；可在管理页改正或遗忘。人物卡和相关记忆通过临时 JSON 资料注入当前模型请求，原始 incoming_text 不被替换，不作为系统指令。角色状态只影响表达，不能证明用户经历或某项计划已经实际完成。

## 主动联系

默认需空闲120分钟，两次至少间隔180分钟，每天最多2次；北京时间23:00–08:00免打扰，连续1次未回应就停止继续主动联系。上述数值均可在管理页调整，界面展示当前未触发原因。

发送仍走原规范联系人绑定、输入检查和单次提交。生成后及真正提交前再次检查暂停、联系人消息水位、模型、人格与管理版本；变化则放弃本次。总暂停／停止自动回复同时阻止后续后台发送。提交已经开始时无法撤回，但不会重发。

发送无唯一回显或结果未知时关闭主动联系；重启保留 UNKNOWN 并停用主动联系，不重放旧动作。被中断或失败的摘要来源保留供手动整理，不自动反复请求。`SENT` 仅指本机观察到回显，不表示手机确认或已读。

现有微信桥的窗口要求仍然有效：前台和后台可用，最小化／托盘发送未开放。
