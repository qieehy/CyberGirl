# Cybergirl 管理控制台

2026-11-18。按用户提供的AstrBot侧栏截图组织工作空间，已在8765上线。布局包括工作台、配置文件、数据与日志、自定义规则，以及扩展分组下的媒体与扩展、人格设定。保留原指定私聊和当前账号的授权范围。

## 可用功能

- 配置文件：模型切换、上下文0–16对、每日模型额度1–30次、回复长度1–96字符；可编辑JSON、从本机导入、导出。修改额度不重置已用次数。
- 数据与日志：当前会话缓存数、今日模型生成数、本机发送回显数、最近100条模型/规则/发送记录；状态筛选、搜索和JSON导出。
- 自定义规则：按顺序匹配原始文本，支持包含/完全一致/前缀和大小写选项；固定回复或忽略。支持启用、编辑、排序、删除、撤销删除和无副作用匹配预览。命中时不调用模型、不消耗模型额度；发送仍通过同一规范联系人校验与单次动作通道。
- 媒体与扩展：分别开关图片理解、表情包理解、语音转文字；关闭的媒体消息不会进入模型。保留已实现的群历史缓存入口。
- 人格设定：编辑人格、快速填入表达方式、查看和载入最近版本；保存旧内容会创建新版本。
- 主题：日间、夜间、跟随系统；在浏览器本地记住选择。桌面侧栏与双栏表单、窄窗口布局均已查看。

配置与规则按会话保存在账号账本，使用版本校验和历史记录。保存会使旧待发送草稿失效；不修改历史发送结果或重发失败消息。人格版本继续沿用既有版本机制。JSON配置是声明式参数，不执行文件中的代码。
